## What's different?


My fork adds a few features on top of the original PlayIntegrityFork:

- **Per-app spoofing** : apply spoofed properties selectively to specific apps.
- **Pause/Resume GMS & Vending spoofing** : temporarily disable or re-enable spoofing without rebooting.
- **Play Store property spoofing** : spoof `BRAND`, `DEVICE`, and `MODEL` reported by the Play Store.


## About

A modified Play Integrity spoofing framework focused on giving users more control over how device properties are spoofed and managed.

This project is designed to work as sub-module for [Integrity-Box](https://github.com/MeowDump/Integrity-Box) ecosystem, with additional functionality built around per-app control, runtime spoofing management, and Play Store property handling.

It is based on the original [PlayIntegrityFork](https://github.com/osm0sis/PlayIntegrityFork) codebase and has been substantially adapted for its current purpose
